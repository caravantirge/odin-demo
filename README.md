# ODIN · Demo

ODIN ist das Betriebssystem für einen Caravan- und Wohnmobilhandel: Bestand, Finanzierung, Auslieferungen, Teile,
Urlaub, Projekte und Wissen an einer Stelle – mit Assistent und „In ODIN arbeiten“ (Änderungen per Satz).

**Demo öffnen:** https://caravantirge.github.io/odin-demo/

- Läuft komplett im Browser (Python per WebAssembly) – kein Server, kein Download, nichts wird gespeichert.
- Anmeldung: beliebige Person wählen, PIN `1234`.
- Alle Daten sind erfunden, Hersteller, Banken und Personen anonymisiert.
